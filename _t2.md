# KARKHANA — Custom Bag Works

A complete, production-ready website for a fictional Indian custom bag manufacturer
specialising in backpacks, school bags, college bags, file bags, duffels and soft
trolleys — plus the design system and the research that produced it.

---

## Run it

`dist/` is a fully static site. No build step, no dependencies, no server required:

```bash
cd dist && python3 -m http.server 8000
# → http://localhost:8000
```

Or just open `dist/index.html` in a browser.

## Rebuild

```bash
cd src
python3 tools/decode_assets.py   # materialise images + fonts from .b64 sources
python3 tools/fonts.py           # (optional) re-fetch webfont subsets
python3 build.py                 # generate dist/
```

> **Why the assets are base64.** The GitHub API integration available here
> passes file content as a JSON string and UTF-8 encodes it server-side, so
> binary files (WebP, WOFF2) are silently corrupted in transit — a byte
> `>= 0x80` expands to two bytes. Base64 is pure ASCII and survives the
> transport byte-for-byte. The repository therefore stores binary assets as
> `<file>.b64` and `build.py` materialises them automatically. Every decoded
> file is checked against its source with a SHA-256 comparison on each build.

```
  assets/                     css · js · fonts · img  (+ .b64 sources)
  tools/                      decode · optimize · fonts · shoot · overflow · qa

```

The Pages workflow decodes the assets, runs the generator and publishes
`dist/`. Enable **Settings → Pages → Source: GitHub Actions** on the repo to
switch it on.

## The one-line idea

Every competitor in this category sells price. This site sells **specification** —
a bag is a manufactured object with tolerances, not a photo on a catalogue page.
So the site publishes them: GSM, denier, stitch density, AQL, shade band, MOQ,
lead time, and a live price band you can build yourself before emailing anyone.

## The signature feature

`customise.html` — a working pricing engine, not a mockup. Pick a silhouette,
fabric, colourway, branding process, hardware finish and lining; the spec card,
price band, MOQ and lead time all recompute from the same formula that builds
the quote, and the configuration carries straight into the RFQ form.

```
unit  = base × fabric.index + branding.unit + hardware.unit + lining.unit
price = unit × tier.multiplier
moq   = max(product.moq, branding.moq, hardware.moq)
lead  = product.lead + fabric.lead + branding.lead + hardware.lead + lining.lead
```

## Notes

- **Zero third-party requests.** Fonts are self-hosted; there is no CDN, no
  analytics, no tracker.
- **No framework.** Vanilla HTML/CSS/JS, hand-written, ~16 KB of JavaScript.
- **Accessibility.** Measured AA contrast on every pair, one `h1` per page, no
  heading-level jumps, labelled fields, keyboard-operable everything, and full
  `prefers-reduced-motion` support.
- **Images are AI-generated** for this project — 13 original product, factory and
  material photographs, produced for the site rather than licensed stock.
